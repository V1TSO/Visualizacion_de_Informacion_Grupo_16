TAXIEl pulso de Nueva York · Prototipo físico-digital

Mientras más rápido va la ciudad, más lejos llega el taxi

Elige una hora y un tipo de día, y arranca el taxi. Durante 5 segundos avanza a la velocidad mediana de los taxis amarillos de Nueva York a esa hora de enero. El punto donde se detiene marca esa velocidad en la regla. Después vuelve solo a la salida.

Modelo 3DLos datos son reales: registros de la NYC TLC, enero de 2019 a 2026. El taxi, la avenida y los controles son una simulación del prototipo físico. Si conectas la maqueta con un celular, el modelo sigue al taxi real.

Este navegador no puede mostrar el modelo 3D. La regla vista desde arriba, el taxímetro, los gráficos y el sonido funcionan igual.

Arrastra para girar la vista y usa la rueda o dos dedos para acercar. En la caja de controles puedes girar la perilla, mover el interruptor y apretar Arrancar.

Lecturas en vivo

Calibrar con el peso real

El pulso no fija la fuerza del servo: fija la velocidad que intenta alcanzar. Con el celular encima, el mismo pulso avanza menos, y uno bajo puede ni moverlo. Con el taxi armado como en la demostración y en la salida, prueba varios pulsos y anota hasta dónde llega la aguja en 5 s; con eso se calcula el pulso de cada velocidad.

Regla: distancia desde la salida hasta la marca de 28 km/h. Vuelta: pulso para volver; si con el peso no alcanza a volver, bájalo (por ejemplo, 1.380). Al cambiarlo, la velocidad de vuelta se vuelve a medir. Quieto: si el taxi sigue moviéndose cuando debería estar detenido, cambia este valor de a 1 o 2 hasta que se quede quieto; se aplica al tiro.

La regla vista desde arriba

Cada carrera deja una banderita en la velocidad donde se detuvo el taxi. Compara las banderitas de una misma hora: la que llega más lejos corresponde al tráfico más rápido.

Los datos de cada hora

La línea punteada marca la hora elegida. La línea gruesa es el tipo de día elegido. Con el taxi en la salida, puedes hacer clic en un gráfico para cambiar la hora.

Cómo se usa

  1. Elige la hora y el tipo de díaGira la perilla para la hora y mueve el interruptor para lunes a viernes o fin de semana.
  2. Aprieta ArrancarEl taxi avanza 5 segundos a la velocidad mediana de esa hora. La pantalla marca la hora y suena la ciudad.
  3. Lee dónde se detuvoLa aguja del taxi apunta a la velocidad en la regla, y ahí queda una banderita con la hora.
  4. El taxi vuelve soloRetrocede despacio y en silencio hasta la salida. La vuelta es siempre igual: no representa datos.

Notas técnicas

Información para construir, conectar y calibrar el prototipo físico. El computador muestra esta página. Un celular Android lleva enchufado el Arduino, le da energía y le dice al servo qué hacer. Los dos se unen con Protobject, el framework del curso.

Conectar la maqueta
  1. Programar el Arduino, una sola vezDesde el computador, con el Arduino IDE, cargar protobject-leonardo-pullup.ino al Leonardo. Necesita las bibliotecas Servo, ArduinoJson y WebUSB; el encabezado del archivo explica cómo instalarlas.
  2. Abrir esta página en el computadorCon Chrome o Edge, en una sola pestaña. La dirección suma ?ptjuid=…: es el canal de esta sesión.
  3. Unir el celularTocar «Conectar celular» en el taxímetro y escanear el QR con un celular Android con Chrome. Se abre la página del celular.
  4. Enchufar el Arduino al celularCon un cable USB-OTG. En el celular, tocar «Conectar Arduino», luego «Confirm», y elegir la placa en la lista. Después, poner el celular sobre el taxi: desde ahí todo se hace en el computador.
  5. Ajustar y calibrarAl conectarse el celular aparece «Ajustes de la maqueta», bajo el modelo 3D. Ahí se marcan las piezas que están cableadas (un pin sin nada conectado da lecturas falsas) y se calibra con el peso real.
  6. Usar la maquetaEl taxímetro dice «Maqueta conectada». Se arranca con «Arrancar» o con «Recorrer el día». Sin microinterruptor de tope, «Ya está en la salida» detiene la vuelta si el taxi llegó antes de lo calculado.

Para probar sin Arduino, agregar &prueba a la dirección que abre el celular: su página simula la placa, el servo y el tope.

El ciclo corre en el celular, junto al Arduino: así el taxi se detiene en el tope aunque la red se atrase. Si se pierde el computador a mitad de una carrera, el celular la termina solo.

    Programa del Arduino firmware de Protobject · C++

    El Leonardo no lleva un programa propio. Corre el firmware genérico de Protobject, que recibe órdenes en JSON por WebUSB (mover el servo, leer los pines) y no sabe nada del taxi. Se diferencia del oficial en tres líneas, para que los interruptores vayan a GND sin resistencias: descargar protobject-leonardo-pullup.ino.

    pinMode(7, INPUT_PULLUP);   // interruptor de tipo de día a GND
pinMode(8, INPUT_PULLUP);   // botón Arrancar a GND
pinMode(9, INPUT_PULLUP);   // microinterruptor de tope a GND
    Programa del navegador Protobject · WebUSB en el celular 
    // config.js: las dos páginas del prototipo
Protobject.initialize([
  { name: 'Pantalla', page: 'index.html', main: true },
  { name: 'Celular con Arduino', page: 'arduino.html' },
]);

// index.html (computador): manda la velocidad de la hora elegida
Protobject.Core.send({ tipo: 'velocidad', kmh: 14.2 }).to('arduino.html');

// arduino.html (celular): conecta la placa y mueve el servo
await Protobject.Arduino.start();                    // pide permiso WebUSB
Protobject.Arduino.onData(d => { lectura = d; });     // a0, d7, d8 y d9 cada 60 ms
Protobject.Core.onReceived(msg => {
  if (msg.tipo === 'velocidad') {
    Protobject.Arduino.contServoWrite({ pin: 5, value: pulsoIda(msg.kmh) });   // 1.500 µs + valor
    Protobject.Core.send({ tipo: 'fase', fase: 'ida' }).to('index.html');
  }
});
    Construcción y calibración
    1. Servo de rotación continuaPara volver, el servo gira al revés con un pulso bajo 1.500 µs. Un servo de 180° no puede hacerlo.
    2. Calibrar con el peso realEl pulso fija la velocidad que el servo intenta alcanzar, no su fuerza: con más peso, el mismo pulso avanza menos, y un pulso bajo puede no moverlo. En «Ajustes de la maqueta», «Calibrar con el peso real» prueba un pulso durante 5 s; se anota hasta dónde llegó la aguja y, con varias mediciones, se calcula el pulso de cada velocidad. La vuelta de cada prueba mide además la velocidad de vuelta, que sin tope decide cuánto dura. Ahí mismo se ajustan el pulso de vuelta, el pulso en que queda quieto y el largo de la regla. Todo se guarda en el celular, que viaja con el taxi.
    3. Tope en la salidaEl servo no gira igual hacia adelante que hacia atrás. El microinterruptor corrige esa diferencia en cada vuelta.
    4. AvenidaRecta, de unos 24 cm de ancho, con bordes de cartón. El taxi mide unos 18 cm de ancho y no tiene dirección. El largo depende de la velocidad máxima del servo: este modelo supone 24 cm/s, es decir, 120 cm en 5 s.
    5. EngranajesEntre los dos ejes tiene que haber una cantidad impar de engranajes. Con una cantidad par, los ejes giran en sentidos opuestos y el taxi se traba.
    6. Dónde va el celularSobre el taxi, junto al Arduino, con un cable OTG corto: así no hay cables colgando, pero el taxi pesa más y hay que calibrar con el celular puesto. La otra opción es dejarlo fijo junto al poste, con un cable USB de unos 2 m colgado desde arriba hasta el Arduino.
    7. AlimentaciónEl celular entrega poca corriente por OTG. Si la placa se reinicia cuando el servo arranca o cambia de sentido, alimentar el servo con una fuente de 5 V aparte, con GND común.
    8. Navegador del celularChrome en Android. En iPhone no funciona: Safari no tiene WebUSB.

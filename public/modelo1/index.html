TAXIEl pulso de Nueva York · Prototipo físico-digital

Mientras más rápido va la ciudad, más lejos llega el taxi

Elige una hora y un tipo de día, y arranca el taxi. Durante 5 segundos avanza a la velocidad mediana de los taxis amarillos de Nueva York a esa hora de enero. El punto donde se detiene marca esa velocidad en la regla. Después vuelve solo a la salida.

Modelo 3DLos datos son reales: registros de la NYC TLC, enero de 2019 a 2026. El taxi, la avenida y los controles son una simulación del prototipo físico.

Este navegador no puede mostrar el modelo 3D. La regla vista desde arriba, el taxímetro, los gráficos y el sonido funcionan igual.

Arrastra para girar la vista y usa la rueda o dos dedos para acercar. En la caja de controles puedes girar la perilla, mover el interruptor y apretar Arrancar.

La regla vista desde arriba

Cada carrera deja una banderita en la velocidad donde se detuvo el taxi. Compara las banderitas de una misma hora: la que llega más lejos corresponde al tráfico más rápido.

Lunes a viernes Fin de semana Todavía no hay banderitas.

Los datos de cada hora

La línea punteada marca la hora elegida. La línea gruesa es el tipo de día elegido. Con el taxi en la salida, puedes hacer clic en un gráfico para cambiar la hora.

Cómo se usa

  1. Elige la hora y el tipo de díaGira la perilla para la hora y mueve el interruptor para lunes a viernes o fin de semana.
  2. Aprieta ArrancarEl taxi avanza 5 segundos a la velocidad mediana de esa hora. La pantalla marca la hora y suena la ciudad.
  3. Lee dónde se detuvoLa aguja del taxi apunta a la velocidad en la regla, y ahí queda una banderita con la hora.
  4. El taxi vuelve soloRetrocede despacio y en silencio hasta la salida. La vuelta es siempre igual: no representa datos.

Registro de la simulación:

    Programa del Arduino C++ · biblioteca Servo 
    #include <Servo.h>

const int PIN_SERVO = 9;
const int PIN_PERILLA = A0;       // potenciómetro de la perilla
const int PIN_DIA = 2;            // interruptor a GND: abierto = lunes a viernes
const int PIN_ARRANCAR = 3;       // botón Arrancar a GND
const int PIN_TOPE = 4;           // microinterruptor a GND: apretado = taxi en la salida
const int PARADO_US = 1500;       // calibrar: pulso en que el servo no gira
const int VUELTA_US = 1420;       // calibrar: retroceso lento y siempre igual
const unsigned long IDA_MS = 5000, PAUSA_MS = 3000, VUELTA_MAX_MS = 15000;

enum Estado { ESPERA, IDA, PAUSA, VUELTA };
Estado estado = ESPERA;
Servo rueda;
unsigned long desde = 0;
int horaAnterior = -1, diaAnterior = -1;
bool botonAntes = false;

void cambiar(Estado nuevo, const char *aviso) {
  estado = nuevo;
  desde = millis();
  Serial.println(aviso);
}

void setup() {
  Serial.begin(115200);           // en el Leonardo, Serial usa el mismo cable USB
  Serial.setTimeout(50);
  pinMode(PIN_DIA, INPUT_PULLUP);
  pinMode(PIN_ARRANCAR, INPUT_PULLUP);
  pinMode(PIN_TOPE, INPUT_PULLUP);
  rueda.attach(PIN_SERVO);
  rueda.writeMicroseconds(PARADO_US);
}

void loop() {
  unsigned long t = millis() - desde;
  bool enSalida = digitalRead(PIN_TOPE) == LOW;

  if (estado == ESPERA) {
    int hora = map(analogRead(PIN_PERILLA), 0, 1024, 0, 24);   // 0 a 23
    int dia = digitalRead(PIN_DIA) == HIGH ? 0 : 1;            // 0 = S, 1 = F
    if (hora != horaAnterior || dia != diaAnterior) {
      Serial.print('H');
      if (hora < 10) Serial.print('0');
      Serial.print(hora);
      Serial.println(dia == 0 ? " S" : " F");                  // ejemplo: H08 S
      horaAnterior = hora;
      diaAnterior = dia;
    }
    bool boton = digitalRead(PIN_ARRANCAR) == LOW;
    if (boton && !botonAntes && enSalida) Serial.println("SALIR");
    botonAntes = boton;
  }

  if (Serial.available()) {
    String linea = Serial.readStringUntil('\n');             // ejemplo: V14.2
    if (estado == ESPERA && enSalida && linea.startsWith("V")) {
      float kmh = constrain(linea.substring(1).toFloat(), 10, 28);
      rueda.writeMicroseconds(1560 + (kmh - 10) / 18 * 140);  // calibrar con la regla
      cambiar(IDA, "IDA");
    }
  }

  if (estado == IDA && t >= IDA_MS) {
    rueda.writeMicroseconds(PARADO_US);
    cambiar(PAUSA, "PAUSA");
  } else if (estado == PAUSA && t >= PAUSA_MS) {
    rueda.writeMicroseconds(VUELTA_US);
    cambiar(VUELTA, "VUELTA");
  } else if (estado == VUELTA && (enSalida || t >= VUELTA_MAX_MS)) {
    rueda.writeMicroseconds(PARADO_US);
    cambiar(ESPERA, enSalida ? "SALIDA" : "SIN_TOPE");
  }
}

    Construcción y calibración
    1. Servo de rotación continuaPara volver, el servo gira al revés con un pulso bajo 1.500 µs. Un servo de 180° no puede hacerlo.
    2. Regla medida con carreras realesCorrer el taxi 3 veces con cada velocidad, de 10 a 28 km/h, y marcar dónde se detiene la aguja. El giro del servo no cambia en línea recta con el pulso.
    3. Tope en la salidaEl servo no gira igual hacia adelante que hacia atrás. El microinterruptor corrige esa diferencia en cada vuelta.
    4. AvenidaRecta, de unos 24 cm de ancho, con bordes de cartón. El taxi mide unos 18 cm de ancho y no tiene dirección. El largo depende de la velocidad máxima del servo: este modelo supone 24 cm/s, es decir, 120 cm en 5 s.
    5. EngranajesEntre los dos ejes tiene que haber una cantidad impar de engranajes. Con una cantidad par, los ejes giran en sentidos opuestos y el taxi se traba.
    6. Cable USBDe unos 2 m, colgado desde un punto alto sobre la avenida para que no frene al taxi.
    7. AlimentaciónSi la placa se reinicia cuando el servo arranca o cambia de sentido, usar una fuente de 5 V aparte, con GND común.
